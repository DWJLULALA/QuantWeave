## 创作意图

不做「收益曲线 + 夸张数字」的量化宣传。QuantWeave 真正稀缺的是**研究过程的可复现性**：数据是否新鲜、结构是否偷看未来、结论能不能回放、任务有没有留下产物。

因此片子的叙事不是「看我赚了多少」，而是：

```text
问题：研究散落在脚本里
  → 收拢：一个工作台
  → 深入：数据 / 因子 / 结构 / 模型
  → 闭环：账户 / 记录 / 产物
  → 主张：可复现，才是研究的基础设施
```

视觉语言：深色终端感、青色强调、等宽小标签。全片不使用静态页面推拉，所有功能镜头都是**真实鼠标操作**：点击运行、修改参数、切换周线、拖动时间轴、搜索股票、录入持仓。

## 声音设计

- **旁白**：普通话男声，口语化、克制，像产品作者在介绍自己的工作台；
- **音乐**：原创极简氛围电子，96 BPM，Am–F–C–G 四和弦循环；低频 pad + 稀疏琶音，比人声低约 10 dB；
- **音效**：不使用额外音效，避免与界面信息争夺注意力；
- **整体响度**：-16.7 LUFS，峰值 -1.3 dBFS。

## 界面录制方式

- Playwright + Chromium `recordVideo`，viewport 1920×1080，`timezoneId=Asia/Shanghai`；
- 页面内注入白色箭头光标与青色点击涟漪，所有点击、输入、滚动都是真实事件；
- 每段录屏裁掉 1.0s 载入，尾部用 `tpad` 补足旁白长度；
- 运行类操作等待 demo job 完成（约 5–7s），再滚动到 `DONE` 日志，避免展示“进度条满但仍排队”的中间态；
- 录制地址 `http://127.0.0.1:7072`，与 README 截图同源。
